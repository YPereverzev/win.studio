# Auralis Nails

German marketing site for a nail salon (Maniküre/Pediküre, Wimpernverlängerung, Waxing).  
Next.js App Router · TypeScript · Tailwind.

Inspired structurally by deluxe-spacenter.de; original copy and branding.

## Run locally

```bash
npm install
npm run build
npm run start -- -p 3000 -H 0.0.0.0
```

Or: `npm run dev -- -H 0.0.0.0 -p 3000`

Open [http://127.0.0.1:3000](http://127.0.0.1:3000).

## Pages

- `/` — Home
- `/manikuere` — Maniküre & Pediküre
- `/wimpern` — Wimpernverlängerung
- `/waxing` — Waxing & Epilation
- `/preise` — Preise

- `/ueber-uns` — Über uns
